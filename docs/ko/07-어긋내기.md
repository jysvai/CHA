# 07 — 어긋내기

**English: [07-mutation.md](../en/07-mutation.md)**

고친 줄을 **일부러 망가뜨리고**, 그 줄을 지킨다는 검사가 빨개지는지 봅니다.

고침마다 어긋을 하나씩 박습니다. 고치고 나서 바로, 아직 **어느 글자가 뜻을 지고 있었는지 기억할 때** 씁니다.

---

## 왜 필요한가

`npm test` 가 초록인 것은 **「아무도 안 망가뜨렸다」**는 뜻입니다.

**「망가뜨리면 뭔가 알아챈다」**는 뜻이 아닙니다.

이 둘은 밖에서 보면 **똑같이 생겼고**, 값은 정반대입니다. 앞엣것은 어제 아무 일도 안 일어났다는 보고서이고, 뒤엣것만 내일을 막아 줍니다.

어긋내기는 반대 방향을 잽니다. 줄을 일부러 깨고, 짝 지어진 검사가 빨개지는지 봅니다. 그대로 초록이면 그 검사는 이름이 뭐라고 적혀 있든 **그 줄을 안 지키고 있습니다.**

---

## 판정 셋

| | | |
|---|---|---|
| **잡음** | caught | 짝 지어진 검사가 빨개졌다. 좋다. |
| **샜음** | leaked | 다 초록이었다. **검사의 구멍**이고, 그 자체가 지적이다. |
| **못 잼** | unmeasurable | 앵커가 정확히 한 번 안 맞았거나, 짝 지은 검사가 없거나, 그 검사가 이미 빨갰다. |

### 못 잼은 건너뜀이 아니라 실패다

이게 이 문서의 핵심입니다.

앵커가 조용히 안 맞게 되면, 그 어긋은 **돌아가고 · 아무것도 안 재고 · 전체 숫자를 건강하게 유지하는 JSON 한 줄**이 됩니다.

그건 [다섯 갈래](04-브리핑.md) 중 두 번째 — 조용한 실패 — 이고, 이 도구가 바로 그걸 잡으려고 있습니다. **그 결함이 도구 안에 사는 것**입니다.

그래서 못 잼은 실패로 셉니다. 전수 결과에 못 잼이 하나라도 있으면 그 회차는 안 끝납니다.

---

## 앵커 규칙

앵커(`찾을것`)는 소스에서 바꿀 그 글자열입니다. 규칙 하나하나가 실제로 당한 일입니다.

### 1. 파일에서 그대로 떠 온다. 절대 다시 타이핑하지 않는다

공백 한 칸이 달라지면 **그 앵커는 영영 안 맞습니다.** 그리고 안 맞는 앵커는 조용합니다.

`tools/add-mutant.mjs` 가 있는 이유가 이것입니다. 「조심하십시오」라는 문단 대신 도구를 둔 겁니다. 줄 번호를 주면 그 줄을 디스크에서 읽어서 앵커로 씁니다.

```bash
node tools/add-mutant.mjs src/agent/recall.js 88 \
  --test test/recall.test.js \
  --what "only the longest match scores" \
  --then "a 3-variant word outranks a 1-variant word" \
  --replace "const 다맞음 = 맞은낱말 >= 1 ? 12 : 0;"
```

`--replace` 는 빼도 됩니다. 그러면 `바꿀것` 이 비어서 기록되고, 도구가 그렇다고 말합니다. **못 끝낸 어긋은 기억하는 것보다 보이는 게 낫습니다.**

### 2. 정확히 한 번 맞아야 한다

0번이든 여러 번이든 **시끄럽게 실패**합니다.

여러 번 맞으면 어느 자리를 깨는지 모릅니다. 0번이면 아무것도 안 깹니다. 조용히 건너뛰면 어긋 목록이 **장식으로 썩고**, 전수는 계속 건강한 숫자를 찍습니다.

`mutate.mjs` 는 `찾을것 matched 0 times (must be exactly 1)` 같은 까닭을 붙여 못 잼으로 냅니다.

### 3. `검사` 는 별명이 아니라 **진짜 경로**여야 한다

별명 하나가 **전수 한 판을 통째로 날렸습니다.** 어긋 둘이 돌았고, 아무것도 안 쟀고, 합계는 멀쩡해 보였습니다.

`검사: "recall 검사"` 는 경로가 아닙니다. `검사: "test/recall.test.js"` 가 경로입니다.

지금은 맨 처음 기준선을 잴 때 걸립니다 — 그 경로에 파일이 없으면 `검사/test is not a real path` 로 못 잼입니다.

### 4. 무동작 어긋을 보고한다

`찾을것 === 바꿀것` 이면 아무것도 안 바꾼 것입니다.

이걸 그냥 돌리면 「잡음」이나 「샜음」이 나오는데, 둘 다 **거짓말**입니다. 특히 「샜음」이 나오면 **없는 구멍을 찾으러** 검사 파일을 파헤치게 됩니다. 그래서 `no-op mutant: 찾을것 === 바꿀것` 으로 못 잼을 냅니다.

### 5. 호출하는 자리를 깬다. 편한 헬퍼를 깨지 않는다

**어긋 하나가 이것 때문에 샜습니다.**

헬퍼는 다른 데서 많이 쓰여서 잘 덮여 있었습니다. 헬퍼를 깨니까 검사가 빨개졌고, 「잡힘」이 나왔습니다. 그런데 정작 방금 고친 **호출 자리**는 아무 검사도 안 지키고 있었습니다.

어긋은 **고친 그 줄**을 깨야 합니다. 그 줄이 헬퍼 호출이면, 호출문을 깨는 것이지 헬퍼 안쪽을 깨는 게 아닙니다.

---

## 제자리에서 안 깬다

`mutate.mjs` 는 소스를 **임시 폴더로 베껴 놓고** 거기서만 씁니다.

Ctrl+C 나, 프로세스를 통째로 내리는 검사 하나가 **일부러 망가뜨린 파일을 디스크에 남기면** 안 됩니다. 그걸 커밋하는 것이, 이 도구가 막는 어떤 것보다 나쁩니다.

임시 폴더 안에서도 복원은 `finally` 에 있습니다.

```js
try { r = 돌리기(어긋.검사); } finally { writeFileSync(파일, 원본, 'utf8'); }
```

`베낄것`(`mutate.copy`)에는 검사가 돌아가는 데 필요한 것이 전부 들어가야 합니다. 빠지면 전부 빨개지고, 그건 어긋이 잡힌 게 아니라 **하네스가 깨진 것**입니다.

---

## 기준선 먼저

어긋을 넣기 전에 짝 지어진 검사들을 **그대로 한 번** 돌립니다.

**이미 빨간 검사는 아무것도 못 잽니다.** 깨든 안 깨든 빨갛습니다. 이런 건 `<파일> was already red before the mutation` 으로 못 잼입니다.

```
  · baseline test/recall.test.js → green · 1.4s
  ✗ baseline test/proxy.test.js → exit 1 · 0.9s
```

---

## 앵커 낡음

소스가 바뀌면 앵커가 안 맞게 됩니다. 정상입니다. **조용한 게 문제입니다.**

```bash
node tools/repair-anchors.mjs
node tools/repair-anchors.mjs --write
```

`--write` 없이는 무엇이 낡았는지만 보고합니다. 고칠 때도 **파일에서 그대로 떠 옵니다** — 규칙 1 은 여기서도 같습니다.

---

## 돌리기

```bash
node tools/mutate.mjs                  # 전수
node tools/mutate.mjs src/foo.js       # 어긋의 곳 또는 무엇에 이 글자가 들어간 것만
node tools/mutate.mjs --id recall-042  # 하나만
node tools/mutate.mjs --json           # 기계가 읽을 요약
```

전수는 몇 시간입니다. 방금 옮긴 울타리 하나를 재려고 그걸 다 기다려야 하면 **사람은 재는 걸 그만둡니다.** 그래서 조각으로 돌리는 길이 있고, 조각으로 돌릴 때는 화면에 **몇 개를 걸러 냈는지**가 항상 찍힙니다.

```
  filtered — 6 of 1,179 (src/foo.js)
```

얼마를 건너뛰었는지 모르고 초록을 보는 것이 제일 나쁜 결과입니다.

### 찍히는 꼴

```
  ✓ recall-042 only the longest match scores   src/agent/recall.js → test/recall.test.js caught it · 1.4s

  ✗ proxy-011 header stripped before logging   src/backend/proxy.js
      test/proxy.test.js stayed green — nothing stops the next person deleting this line.
      the cause disappears from the log

  ⚠ scan-007 offline seal checked late   src/backend/scan.js — 찾을것 matched 0 times (must be exactly 1)

  1,125 잡음/caught · 2 샜음/leaked · 22 못잼/unmeasurable
```

---

## 전수에서 나온 숫자

등록된 어긋은 **1,179개**, 소스 138 파일 / 검사 119 파일에 걸쳐 있습니다.

마지막 전수는 **1,149개 · 2시간 46분 → 잡음 1,125 · 샜음 2 · 못 잼 22**.

**스물넷 중 위험한 쪽은 22 입니다.** 샜음 2개는 정직한 구멍입니다 — 검사가 그 줄을 안 지키고 있고, 그렇게 보고됩니다. 못 잼 22개는 **목록에 이름이 있었고 · 개수에 세어졌고 · 아무것도 안 재고 있었습니다.** 빨간 판에서도 초록 판에서도 안 보입니다. 전수를 돌리기 전에는 저 22개가 존재한다는 사실 자체를 몰랐습니다.

초록 뒤에 숨는 게 뭔지 알고 싶으면 이 숫자를 보면 됩니다.

---

## 다른 일 하는 기계에서는 전수를 안 돌린다

시간에 민감한 일을 같이 돌리는 기계에서 전수를 돌리면, **부하 때문에 시간 초과된 검사가 「샜음」으로 보고됩니다.**

`mutate.mjs` 는 검사의 종료 코드만 봅니다. 시간 초과로 죽은 검사는 0 이 아닌 코드로 죽고 — 그건 「잡음」 쪽이라 안전합니다. 문제는 반대쪽입니다: 기준선이 부하 때문에 느려져서 통과 직전에 걸리거나, 타이밍을 재는 검사가 어긋과 상관없이 흔들리는 경우입니다.

그러면 **없는 구멍을 찾으러** 갑니다. 검사 파일을 읽고, 단언을 뜯어 보고, 아무 문제도 못 찾습니다. 시간만 씁니다.

전수는 한가한 기계에서 돌립니다. 샜음이 나오면 **그 하나만 다시 돌려서** 확인합니다.

```bash
node tools/mutate.mjs --id proxy-011
```

---

## 고침마다 하나

어긋 없는 고침은 **아무도 안 지키는 고침**입니다. 다음 사람이 그 줄을 지워도 아무 일도 안 일어나고, 언젠가 그렇게 됩니다.

고치고 → 검사 초록 확인하고 → 그 자리에서 어긋을 박습니다. 「나중에 몰아서」는 안 됩니다. 며칠 지나면 어느 글자가 뜻을 지고 있었는지 기억이 안 납니다.
