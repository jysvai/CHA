# CHA — 순환형 적대적 하네싱 (Cyclic Hostile Adversarial Harnessing)

**English: [README.md](README.md)**

코딩 에이전트를 위한 **배포 문턱 루프**입니다. 린터도 아니고 프롬프트 모음도 아닙니다 — 이슈가 0 이 될 때까지 안 멈추고, **자기가 돌려 보지 않은 것은 믿지 않는** 절차입니다.

> 나머지를 다 떠받치는 규칙 하나: **돌려 보기 전에는 결함이 아니다.**

---

## 왜 필요한가

코딩 에이전트가 제 코드를 스스로 검토하는 것은, 고를 수 있는 검토자 중 **제일 못 믿을** 검토자를 고르는 일입니다. 그 코드를 제가 썼고, 같은 주석을 읽었고, 같은 자리가 안 보입니다. 그리고 확신이 없을 때 매끄럽고 자신 있는 **틀린 답**을 냅니다.

흔한 처방은 안 듣습니다.

| 처방 | 왜 안 듣나 |
|---|---|
| "네 diff 를 검토해 봐" | 같은 모델 · 같은 맥락 · 같은 사각지대. |
| 같은 모델로 한 번 더 | 오류가 **상관**되어 있습니다. 자기 말에 동의합니다. |
| 더 센 린터 | 모양은 보지만 **거짓말**은 못 봅니다. 코드와 어긋난 주석은 초록입니다. |
| 검사를 더 | **아무것도 안 재는 검사**도 초록입니다. 아무도 모릅니다. |

CHA 는 **역할을 플랫폼째 가르고, 안 돌려 본 주장은 통과시키지 않는 것**으로 이걸 막습니다.

- **다른 플랫폼이 본다** (Gemini · Codex · GPT — 2차 눈은 무엇이든). 학습이 다르고 실패 방식이 달라서, **환각이 서로 상관되지 않습니다.**
- **코드는 한 곳만 쓴다** (Claude). 수정이 한 줄로 서서, 고침이 반만 붙는 일이 안 납니다.
- **모든 주장은 실행으로 가른다.** 실제로 잰 회차에서 **지적 57건 → 참 22건**. 자신 있게 올라온 것의 **열에 여섯이 틀렸고**, 읽기만 해서는 어느 쪽이 어느 쪽인지 알 수 없었습니다.
- **고치기 전에 빨간 것을 먼저 증명**하고, 그다음 초록으로 만듭니다.
- **고친 자리마다 어긋(변이)을 박는다.** 고친 줄을 일부러 망가뜨려 검사가 빨개지는지 봅니다. 그대로 초록이면 그 고침은 **아무도 안 지키고 있는 것**이고, 언젠가 누가 지웁니다.
- **거짓 경고도 결함이다.** 없는 고장을 말하는 코드는 조용한 코드와 값이 같습니다.

## 실제 저장소에서 잰 숫자

CHA 는 책상에서 설계한 것이 아니라, `deel` — 의존성 0 짜리 Node CLI 코딩 에이전트 — 의 **6회차 배포 검수**에서 뽑아낸 절차입니다.

| | |
|---|---|
| 검수 대상 | **171 파일 · 77,607 줄** |
| 검사 | **154 파일 · 75,499 줄** |
| 마지막 관문의 검사 결과 | **12,596 통과 · 0 실패 · 1 건너뜀 · 파일 156/156 정상 종료** |
| 등록된 어긋(변이) | **1,179개** · 소스 138 파일 / 검사 119 파일에 걸침 |
| 마지막 전수 어긋내기 | **1,149개 · 2시간 46분 · 잡음 1,125 · 샜음 2 · 못 잼 22** — 스물넷 전부 해결 |
| 돌린 관문 | **39회** |
| 마지막 회차 2차 눈 브리핑 | **39판** |
| 올라온 지적 → 실행으로 확인된 참 | **57 → 22** |
| 그 회차에 실제로 고친 자리 | **19곳** |
| 누적 기록 | **2,745줄** · 한 번도 안 지움 |
| 커밋 | **434개** |

**초록 뒤에 숨어 있던 스물넷.** 전수 어긋내기가 찾아낸 것은 「아무 검사도 안 잡는 어긋 2개」와 「앵커가 낡아 **아무것도 안 재고 있던** 어긋 22개」였습니다. 뒤엣것이 더 위험합니다 — 목록에 이름이 있고, 개수에 세어지고, 빨강으로도 초록으로도 **안 보입니다.**

## 조각들이 어떻게 붙나

쓸 수 있는 것은 전부 선 한쪽에 있습니다 — 플러그인, 도구들, `.cha/` 파일들, 그리고 코드를 고치는 하나뿐인 에이전트. 2차 눈은 반대쪽에 있습니다. 다른 플랫폼이고, 모델 id 를 못박았고, **쓰기 도구도 셸도 저장소 접근도 없습니다.** 브리핑 글이 한 방향으로 건너가고 지적 글이 되돌아올 뿐, 그 밖에는 아무것도 안 건너갑니다.

이 선은 믿고 안 믿고의 문제가 아닙니다. 쓰는 곳이 둘이면 **두 수정이 만나는 자리를 아무도 안 읽습니다.** 한쪽이 봉인을 옮기고 다른 쪽이 그 봉인이 지키던 것을 옮기면, 각자 검사는 따로 초록이고 결함은 그 사이에 삽니다. 잰 회차에서 나온 「반만 붙은 고침」은 전부 이 모양이었습니다 — 머리말은 옳은 행동을 적고 있는데 코드는 두 부르는 자리 중 한 군데만 그렇게 하는 것. **세 번 나왔습니다.**

## 설치

```bash
# 1. 이 저장소를 플러그인 장터로 등록
/plugin marketplace add jysvai/CHA

# 2. 설치
/plugin install cha@cha
```

로컬 클론으로 써도 됩니다.

```bash
git clone https://github.com/jysvai/CHA ~/cha
/plugin marketplace add ~/cha
/plugin install cha@cha
```

그다음, 검수할 저장소에서:

```
/cha-init
```

`.cha/`(설정 · 누적 기록 · 어긋 목록)를 깔고, 2차 눈에 무엇이 필요한지 알려 줍니다.

2차 눈 CLI · 한도 처리 · **2차 플랫폼이 아예 없을 때** 까지 포함한 설치 전부는 **[docs/ko/01-설치.md](docs/ko/01-설치.md)** 에 있습니다.

## 명령

| 명령 | 하는 일 |
|---|---|
| `/cha-init` | 지금 저장소에 `.cha/` 를 깔고 관문 명령을 알아낸다. |
| `/cha-hunt <경로>` | 1차 눈 훑기. **판정이 아니라 의심**을 낸다. |
| `/cha-brief <경로>` | 파일을 20KB 이하 브리핑으로 자르고 다섯 갈래를 붙인다. |
| `/cha-review2` | 밀린 브리핑을 2차 눈에 **한 판씩** 보낸다. 한도를 안다. |
| `/cha-judge <태그>` | 답 하나를 **실행으로** 가른다. 근거와 함께 참/거짓/못 잼을 적는다. |
| `/cha-fix <번호>` | 빨간 검사 먼저 · 그다음 고침 · 그다음 어긋. 순서를 안 바꾼다. |
| `/cha-mutate [거르개]` | 어긋내기를 돌린다. 전수든, 한 파일만이든. |
| `/cha-gate` | 관문을 다 돌리고, **안 잰 것을 초록이라고 안 적는다.** |
| `/cha-record` | 이번 회차를 누적 기록에 보탠다. |
| `/cha-status` | 루프가 어디까지 왔나 — 밀린 브리핑 · 안 가른 답 · 안 지켜지는 고침. |

## 다섯 갈래 결함

브리핑마다 이 다섯을 붙입니다. 여섯 회차를 살아남은 갈래이고, **린터가 못 보고 같은 모델이 이름 붙이지 못하는** 것들입니다.

1. **실제 입력에 절대 안 맞는 규칙.** `/(1b|2b|3b)/` 가 `qwen2.5-coder:32b` — 32B 모델 — 을 「작은 모델」로 셌습니다. `32b` 안에 `2b` 가 들어 있어서요.
2. **조용한 실패.** 못 읽은 시트를 `catch { continue; }` 로 건너뛰고, 결과는 「다 읽었습니다」 였습니다.
3. **안 지키는 검사.** 이름은 `「셈이 숫자가 아니면 안 받는다」` 인데 `'many'` 하나만 물어봐서, `'3'`·`null`·`true`·`[]` 가 전부 그냥 지났습니다.
4. **주석과 코드의 모순.** 머리말은 「`ok` 없는 줄은 성공으로 안 친다」 인데 코드는 성공으로 셌고, 실패율이 실제보다 낮게 나왔습니다.
5. **신뢰 경계 누수.** `--offline` 봉인을 **바깥 주소를 세 번 두드린 뒤에** — 열쇠까지 실어 보낸 뒤에 — 봤습니다.

## CHA 가 **안 하는** 것

- **못 잰 것은 안 고칩니다.** 마지막 회차의 지적 4건은 플랫폼에 묶여 있었습니다(유닉스 전용이거나, 엑셀이 깔려 있어야 함). **못 잼**으로 적었지 짐작으로 고치지 않았습니다. 안 돌려 본 주장에 고침을 지어내는 것이, 바로 CHA 가 막으려는 그 실패입니다.
- **검토자에게 코드를 안 맡깁니다.** 2차 눈은 읽기 전용입니다. 쓰는 곳은 언제나 하나.
- **안 돌려 본 것을 초록이라고 안 적습니다.** 못 잰 어긋은 **실패**로 셉니다. 조용한 것은 성공이 아닙니다.
- **혼자 배포하지 않습니다.** 태그·푸시는 검수 범위를 보고하고 사람이 허락한 뒤에만.
